# Flone - Responsive E-Commerce Website

A modern responsive e-commerce landing page built with Bootstrap 5.3, HTML5, and CSS3.

## Features

- Responsive Navbar
- Hero Carousel Slider
- Feature Section
- Product Grid
- Blog Section
- Modern Footer
- Responsive Design
- Bootstrap 5.3
- Font Awesome Icons
- Google Fonts (Poppins)
- Smooth Hover Animations
- Mobile First Layout

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3
- Font Awesome
- Google Fonts

## Folder Structure


project/
│
├── index.html
├── styles.css
└── README.md


## Getting Started

1. Clone the repository


git clone https://github.com/MdUsmanKhans/Landing-page-for-fashion-web.git


2. Open the project folder.

3. Run `index.html` in your browser.
